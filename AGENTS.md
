# Testing Rules

A test that does not exercise real behavior against real data is a liability, not an asset.

## Core Rules

1. **Characterize before asserting.** Run code with real inputs. Observe real output. Record as golden file. Only then write assertions.
2. **Install dependencies first.** Resolve the full dependency tree before the first line executes. Complete environment before any code runs.
3. **Real data, real services, real infrastructure.** Every test exercises the actual runtime path. Pay the cost of real execution.
4. **Verified fakes only.** Mocks/stubs permitted only for dependencies whose real behavior you observed and captured this session.
5. **Every golden file gets an anti-fixture.** Plausible-but-wrong output. Test PASSES with golden, FAILS with anti-fixture. Passes both = fix the assertion.
6. **Fail first.** Confirm every test can fail. Mutate input or break implementation. A test never seen failing has never proven it detects faults.
7. **Preserve behavior under failure.** Fix root causes. No weakening validations, swallowing exceptions, stubbing real calls, or downgrading assertions to pass tests.
8. **One command runs everything.** Single top-level command installs, builds, and runs every test. Unwired tests do not exist.

## Strategy Flow

Capture (real execution) → Observe I/O → Promote to golden files → Anti-fixtures → Tests at all pyramid layers → Prove discriminating power → Wire into build → Update RTM

## File Structure

```
features/
  RTM.md
  <feature>/
    SPEC.md
    golden/
    fixtures/
      inputs/
      anti-fixtures/
contracts/
  <provider>/
.testing/                    # gitignored
  captures/                  # raw I/O from real execution
  logs/                      # structured logs from captures
  actions/                   # action prompts
  reference.md               # terminology reference
```

## Available Skills

| Skill | Purpose |
|-------|---------|
| `/test-capture` | Run code with real inputs, capture raw I/O (no tests) |
| `/test-live` | Execute as a real user, capture full session |
| `/test-diverse` | Generate diverse inputs, run all for real, categorize results |
| `/test-plan` | Characterize a feature, capture fixtures, plan test coverage |
| `/test-implement` | Start implementation in worktree with baseline fixture verification |
| `/test-check` | Compare current state vs plan, check fixture drift, RTM progress |
| `/test-bootstrap` | Set up test infrastructure from scratch |
| `/test-feature` | Add full pyramid coverage for one feature |
| `/test-bugfix` | Red-Green-Refactor TDD for a bug |
| `/test-golden` | Capture or refresh golden files |
| `/test-audit` | Audit entire test suite for quality and completeness |
| `/test-pre-merge` | 8-gate pre-merge verification checklist |
| `/test-contracts` | Set up consumer-driven contract tests |
